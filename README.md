# UAG_proyecto_Analizador-de-rendimiento-acad-mico
Una escuela necesita un programa que les permita a los profesores ingresar las calificaciones, a los estudiantes consultar su promedio y a los coordinadores obtener un resumen de las calificaciones con alertas en casos especiales.

Integrantes: Abril Daniela Ojeda, Ana Victoria Robles, Paulina Montserrat Valencia, Uriel Emiliano López.
